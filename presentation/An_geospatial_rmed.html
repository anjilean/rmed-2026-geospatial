What is GIS?

A Geographic Information System (GIS) links locational (spatial) and database (tabular) information and enables users to visualize patterns, relationships, and trends.

This process gives an entirely new perspective to data analysis that can’t be gathered from table or list form.

GIS Specific Software

R is very powerful and can accomplish a lot of geospatial analysis, but there are also lots of things it can’t do (or aren’t meant to do).

Some other software to explore:

  • ArcGIS (paid - “gold standard”)

  • QGIS (open source version of ArcGIS)

  • Google Earth Pro

  • GeoDa

Types of Geospatial Data

There are two main types of geospatial data, vector and raster:

  • Vector data is very common in social sciences since many features used have discrete boundaries (for example, state or county lines)

  • Raster data is utilized mostly in environmental sciences (remote sensing data comes in as image, more continuous in nature)

Layered Model of GIS

Types of Maps

There are many different types of maps for all types of purposes:

  • Physical maps show landscape features like rivers and land masses

  • Topographic maps show contours of elevation lines

  • Climate maps show atmospheric conditions

  • Reference or mental maps show an adjusted version of a map like a “You Are Here” map of the mall, or scaled subway system map

  • Chloropleth maps shows differences between areas using shading or coloring (heat maps are a version)

Coordinate Reference System

The Coordinate Reference System (CRS) is why maps showing the same area look distorted - the CRS is crucial as it ties the vector and raster data types together to a location on the earth:

Geospatial Data Sources

If the map data you want is not available in a package, you can also use shapefiles that represents the area. You can find them easily online (NYC OpenData, ERSI, TIGER GIS) as they are the standard for GIS software.

When you download a shapefile, it’ll come as a folder with a bunch of different files - do NOT separate them! nybb is the New York borough boundaries, and nyc_supermarkets has the locations of supermarkets in the city.

Package Overview

{ggplot2}

{ggplot2} can easily map using longitude and latittude as x- and y- axes. Syntax is familiar so easy to pick up.

ggplot(data, aes(x = longitude, y = latitude)) +
  geom_polygon()

{ggplot2}

There are maps that you can load easily (“county”, “france”, “italy”, “nz”, “state”, “usa”, “world”, or “world2”) using the map_data() function:

# load the contiguous US states

{tmap}

The {tmap} package (thematic maps) resembles {ggplot2} syntax, but tailored to maps. You can customize your plots endlessly - change colors, choose color of missing categories, legend position, scale, size, labels etc.

library(tmap)

# basic map
tm_shape(shapefile) + 
  tm_polygons()
